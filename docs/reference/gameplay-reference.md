# Gameplay Reference — Spend-Money Genre

> Status: Reference only / Non-normative  
> Observed: 2026-08-17

## 1. Reference

Primary page examined: `spend-elon-money.com/zh-cn/`.

This file exists to document genre observations and **prevent accidental cloning** by distinguishing inspiration from our own requirements.

## 2. Observed reference-site behavior

At the time of review, the page showed:

- title centered on spending Elon Musk's money;
- representative balance of `$250,000,000,000`;
- a long product list from inexpensive items to multi-billion-dollar items;
- quantity inputs and live subtotals;
- spend-progress display;
- receipt section;
- 16 achievements;
- challenge selector for 30, 60, and 300 seconds;
- completion/result messaging;
- disclaimer language explaining that it is an unofficial entertainment simulation and the balance is representative rather than real-time.

## 3. Genre mechanics worth preserving conceptually

These are generic mechanics rather than copied content:

- huge starting balance;
- increasing purchase scale;
- quantity-based spending;
- immediate numerical feedback;
- receipt/result summary;
- achievement goals;
- optional speed challenges.

## 4. What this project changes intentionally

| Reference observation        | Spend_Musk_Money direction                        |
| ---------------------------- | ------------------------------------------------- |
| $250B representative balance | Fixed original baseline of $400B                  |
| Reference catalog            | Independently authored 10-category catalog        |
| 16 reference achievements    | Independently authored achievement rules/names    |
| Reference layout/copy        | Original modern-flat design and copy              |
| Web-focused experience       | v1.0 Web/PWA + WeChat parity                      |
| Basic completion statistics  | Richer deterministic result statistics + 败家指数 |
| Reference's product imagery  | Original/licensed asset system                    |

## 5. Prohibited reuse

Do not:

- copy HTML/CSS/JS;
- recreate exact card spacing/colors/layout from screenshots;
- copy the full product sequence and prices;
- copy achievement names/descriptions;
- download/hotlink its product images;
- reuse its prose/SEO/game instructions;
- present the reference brand as our publisher or partner.

## 6. Research note

Reference-site behavior may change later. If it changes, that does not automatically change this project's baseline. Any product change must go through our own requirement process.
